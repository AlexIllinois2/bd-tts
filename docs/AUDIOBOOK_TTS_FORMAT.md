# 听书模式与 `.tts` 文件格式

听书页位于 App 底部导航的「听书」Tab。它把一本 `.tts` 文本当成长音频来播：
逐行离线合成、自动续播、拖动进度、跳到指定行，并在状态栏保留播放控件。

## 1）`.tts` 格式定义

`.tts` 是本 App 自定义的**纯文本**格式，不是音频文件。**本 App 只消费这种格式，不负责生成**：
注音文本由外部产出（例如用「读音」页的示例提示词让 AI 生成，或自行按下面规则编写），
App 只做导入、朗读和展示。

- 编码：UTF-8（允许 BOM；Windows 的 CRLF 换行会自动兼容）。
- 一个**物理行** = 一个朗读单元。引擎按行合成，播完自动进入下一行。
- 行号从 **1** 开始，按物理行计数，和常见文本编辑器看到的行号一致。
- 空行和以 `#` 开头的行**计入行号但不朗读**，可用来分章、写标题或备注。
- 支持引擎已有的内联拼音写法，例如：`银行[[行|hang2]]长`。
- **不使用任何规则文件**：听书朗读期间把引擎规则切到「无规则」内容（不读取、不改动
  「读音」页的三份规则文件及其开关），发音只由 `.tts` 里的 `[[字词|拼音]]` 内联注音决定；
  未注音的字按引擎默认读音。进入 / 退出听书模式时各重建一次引擎，连续朗读不会反复重启；
  停止后自动恢复用户规则，系统 TTS / Legado 的发音不受影响。
  SSML phoneme 会逐字覆写拼音，因此已注音字词不会被任何规则改音。
- **按句 + 片段朗读**：一行先按句末标点（`。！？；!?;…`）切成多句，长句再在逗号 / 顿号 / 冒号处
  切成约 90 字的片段，逐片段合成播放；通知与播放器显示「第 a/b 句」。
- **句尾引号并入**：句末收尾字符包含中文弯引号 `” ’` 和直引号等，`他说：“走吧。”` 是一整句，
  不会把 `”` 单独切成纯标点碎片——那种碎片引擎只会合成几秒静音（表现为段尾停顿）；
  切句与切片都会把漏网的孤立标点碎片并进前一句，合成游标还会跳过不含任何可读字符的片段。
- **流水线预合成**：合成与播放跑在两个线程。producer 用游标按「行 → 句 → 片段」顺序持续合成，
  放进有界队列（默认领先 8 个片段）；播放线程只从队列取现成音频，不再边放边等合成。
  遇到长句时，它的合成会提前藏进前面片段的播放时间里，句间几乎无停顿；播得慢时队列会自动背压，
  不会无限占用内存。首句仍需等一次合成（host2 首次加载模型可能几十秒）。
- 行号仍是定位单位：跳行 / 拖动进度按行，恢复位置回到该行首句。
- **显示与朗读分离**：播放器一次只显示**当前正在朗读的那一句**（不播放时显示该行首句），
  显示区高度固定为一页（屏幕高度减页面留白），不随句子长短变化，位于播放控制区下方；
  内容超出时在区域内上下滚动，换句时自动回到顶部；不堆叠整段文字。
  显示内容按纯文本切句，与合成流水线互不依赖；合成仍使用带注音的原文，显示方式不影响发音。
  整段 `<speak>` SSML 也会剥掉标签后展示。
- 单个片段最多朗读前 2000 字（界面单句显示上限 2 万字），避免畸形长片段拖垮引擎。
- **截断保护**：按字数截断不会劈开 `[[词|拼音]]` 标记或生僻字。截断点落在标记内时，
  会把残标记连同其后内容剥掉再送引擎；切片也会避开标记内部。
  否则 `[[就是|ji` 这样的残片会被引擎当正文逐字母读出（表现为「读着读着飙鸟语」）。

示例：

```
# 第一章
夜色像水一样漫过窗台。
街灯亮了，远处传来列车的汽笛声。

他停下脚步，想起[[重|chong2]]逢的那个下午。
```

这个文件共 5 行，其中第 1、4 行不朗读；「跳转到第 5 行」会直接读到最后一句。

## 2）添加与管理

- 听书页点「添加 .tts 文件」，可一次选多个文件；`.txt` 等文本也可直接添加。
- **文件不复制进 App**：书架保存的是你选中的那个位置（SAF URI + 持久读权限），
  播放和显示都直接从原路径读取；原文件被移动 / 删除 / 权限撤销后，该书会读不到内容，
  需要从书架移除后重新添加。删除书架条目**不会**删除你的原文件。
- 首次添加会为每行记录字节偏移，索引只存到 `filesDir/audiobook/.idx/`（不含正文）；
  原文件大小变化会自动重建索引。播放和显示时按偏移随机读单行，
  **整本书不会一次性进内存**，上百 MB 也能用。
- 书架每行右侧可直接播放，或从书架移除该书及其进度。

## 3）播放与进度

- **记忆 / 恢复**：固定行为（无开关）。播放中每 3 秒落盘一次，暂停、跳行、拖动进度和退出时立即保存行号；
  下次打开书或点「播放」自动从上次那一行继续。想重听，用「跳转到指定行」跳到第 1 行即可。
- **拖动进度**：滑块按「行 + 行内比例」映射整本书；松手即定位。正在播放时从目标行继续播放，
  未播放时只移动光标，点「播放」后从该行开始。
- **跳转行**：播放器卡片右下角「跳转」按钮，输入框显示共多少行，行号越界会提示。
- **定时停止**：「跳转」旁边的「定时」按钮，弹窗输入分钟数（1 - 1440），倒计时结束自动停止播放；
  按钮上显示剩余时间（mm:ss），再次打开可改时长或取消。上次时长会记住，下次自动填入。
  倒计时独立于页面存活，切 Tab / 息屏都不中断（进程被杀则一并失效）。
- **上一行 / 下一行**：按当前朗读单元前后移动行；到首行或末行会停在该行。
- **暂停**：在一行内部立即生效（音频写入使用非阻塞模式）；恢复时从暂停处继续。
  如果当前行还在合成，暂停会在合成完成后、出声前生效。
- **熄屏**：播放期间持有 partial wake lock，停止 / 暂停 / 服务销毁时释放。

## 4）状态栏播放控件

播放后前台服务常驻通知栏，提供「上一行 / 播放暂停 / 下一行 / 停止」四个按钮，
并显示「第 X / Y 行 · 共 Y 行」。点通知内容会打开 App 并落到听书页。
同时注册了系统媒体按键会话，耳机线控 / 蓝牙媒体的播放、暂停、上一曲、下一曲会映射到对应操作。

Android 13+ 首次点播放时会请求 `POST_NOTIFICATIONS`；拒绝后声音照常播放，只是通知可能不显示。
前台服务类型为 `mediaPlayback`，已声明 `FOREGROUND_SERVICE_MEDIA_PLAYBACK` 权限。

## 5）实现位置

| 文件 | 职责 |
| --- | --- |
| `audiobook/TtsBooks.kt` | 书架登记（SAF URI 持久权限）、行偏移索引（侧车缓存）、从原位置按需随机读单行 |
| `audiobook/BookPrefs.kt` | 上次书、每本书记忆的行号、定时时长 |
| `audiobook/AudiobookService.kt` | 前台播放服务、行→句→片段游标、流水线预合成队列、AudioTrack、MediaSession、通知控件 |
| `audiobook/AudiobookText.kt` | 显示用纯文本清洗、按句切分、长句切合成片段，不改合成文本 |
| `audiobook/AudiobookState.kt` | 服务与页面共享的播放状态 |
| `ui/pages/AudiobookPage.kt` | 书架、播放器、进度条、跳行对话框 |
